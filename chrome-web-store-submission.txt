Ekşisözlük Görsel — Chrome Web Store submission

PRIVACY PRACTICES

Single purpose description:
Display inline image previews for image links in Ekşisözlük entries so users can view linked photos while reading the page.

Host permissions justification:
Access to https://eksisozluk.com/* and https://www.eksisozluk.com/* is used by the content script to detect supported image links in entries and display inline previews. Access to https://ibb.co/*, https://imgur.com/* and https://resmim.net/* allows the background service worker to fetch supported image viewer pages and extract direct image URLs, including supported albums and galleries. Requests to these third-party viewer pages omit credentials. This access is necessary to display the images linked in Ekşisözlük entries.

Remote code:
Select "No, I am not using remote code."

If the dashboard still presents a required explanation field:
All JavaScript executed by the extension is included in the extension package. Remote requests retrieve image files and image viewer HTML only. The extension extracts image URLs and metadata from those responses; it does not execute remote scripts, evaluate downloaded code, or load remotely hosted executable modules.

Data usage:
The reviewed 1.0.0 source has no analytics, tracking code, developer-operated collection endpoint, persistent storage of browsing activity, or Cookies/History API access. It processes links in Ekşisözlük entries to display previews. Image and viewer hosts receive ordinary network requests, including the user's IP address and requested resource URL. Same-origin Ekşi viewer requests use the browser's existing session credentials. Third-party viewer fetches omit credentials.
Review the dashboard's data category definitions against this behavior and ensure any privacy policy agrees. Read and complete the required data-use certifications yourself.

Suggested detailed description:
Ekşisözlük Görsel, Ekşisözlük entry’lerindeki görsel bağlantılarını sayfa içinde önizleme olarak gösterir. Fotoğrafları görmek için bağlantıları tek tek açmanıza gerek kalmadan okumaya devam edebilirsiniz.

EkşiUpload, ImgBB, Imgur ve Resmim bağlantılarının yanı sıra doğrudan görsel bağlantılarını da destekler. Görseller, sayfayı kaydırdıkça otomatik olarak yüklenir.

• Görselleri entry içinde görüntüleyin.
• Imgur albüm ve galerilerindeki fotoğraflara göz atın.
• Önizlemeye tıklayarak görseli yeni sekmede açın.
• Sayfadaki düğme veya eklenti simgesi üzerinden önizlemeleri gizleyip yeniden gösterin.

Eklenti yalnızca Ekşisözlük sayfalarında çalışır. Analitik veya takip kodu içermez. Görseller, ilgili görsel barındırma hizmetlerinden yüklenir.

Silinmiş, özel veya erişimi engellenmiş görseller görüntülenemeyebilir.
